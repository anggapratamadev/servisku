# ServisKu — Portfolio Demo Script

Use this flow when demonstrating the project in a portfolio, interview, or GitHub walkthrough.

## 1. Customer

- Login/register as a customer.
- Add a vehicle.
- Create a service booking and enter the complaint.
- Open booking history and monitor the service timeline.

## 2. Admin

- Login as admin.
- Confirm the booking.
- Create/assign a mechanic.
- Monitor booking status.
- Review activity log and notifications.

## 3. Mechanic

- Login as mechanic.
- Open the assigned job.
- Record inspection, diagnosis, action taken, and notes.
- Add spareparts.
- Complete the service.

## 4. Customer payment

- Customer opens the generated invoice.
- Submit the demo payment/proof.
- Wait for admin verification.

## 5. Admin verification

- Open Payments.
- Review the proof.
- Approve or reject with a verification note.

## 6. Portfolio features

- Open the invoice and print view.
- Open QR tracking.
- Review reports and dashboard analytics.
- Open Activity Log and Notification Center.
- Test the read-only REST API using an authenticated browser session.
